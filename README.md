# tang-bd.github.io

Personal site, served via GitHub Pages. The site itself lives in
[`site/`](./site/) — a static HTML/CSS bundle with no build step.

See [`site/README.md`](./site/README.md) for the local-preview
command, the GitHub Pages deploy steps, and how to edit content or
add new pages.

> The previous al-folio Jekyll source lives on the `master` branch
> (and the legacy build on `gh-pages`); both are left untouched.
